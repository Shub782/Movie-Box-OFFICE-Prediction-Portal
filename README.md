**Movie Box Office Prediction Portal**
    **Predict Revenue for Upcoming Movies**

A full-stack web app to predict box office revenue for upcoming movies. Users enter movie details such as budget, runtime, popularity, cast & director scores, marketing, star power, director reputation, genre, release season, franchise/sequel status, and studio type. The app predicts revenue in USD and converts it to INR.

**Features**

Interactive frontend form for entering movie attributes

Real-time revenue prediction using Python backend

Predictions displayed in USD and INR

React frontend communicates with Python backend API

Supports multiple movie attributes for more accurate predictions

**Tech Stack**

Frontend: HTML, CSS, JavaScript.

Backend: Python (app.py)

Libraries/Modules: Any additional modules used for prediction or UI (e.g  Flask, Pandas, NumPy)

**Setup & Usage**

**Backend**

cd backend
pip install -r requirements.txt
python app.py


**Frontend**

cd frontend
npm install
npm start

**First run the backend after that it will the display the localhost address and after that run the frontend**
**Automatically Opens the app in your browser and enter movie details to predict revenue.**
